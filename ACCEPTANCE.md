## 4. Замечания и решения

B-01 закрыто в ТЗ и реализовано: domain.execute и POST commands, по каждой из восьми команд тестируются 201/повтор/409. B-02 закрыто: domain.world/corners, поворот в setDimensions, единая юго-западная привязка, 422 выхода за участок; C-11 пройден на unit/API. Это не подтверждает ещё непроверенные интерфейсные сценарии.

Технические решения в рамках утверждённого стека: встроенный SQLite Node.js 24; десятичная арифметика Decimal; ExcelJS (MIT) для XLSX. Секрет сессии хранится как SHA-256-хэш; CSRF — независимый случайный токен, доступный только владельцу. Срок сессии 30 дней. GET /session добавлен как служебное восстановление CSRF, не новая команда модели. Изменение участка/региона создаёт новый проект через существующий POST projects, без расширения восьми команд. Никаких новых платных/внешних обязательств.
