# Дом мечты · A1

Локальный тестовый стенд по SPEC.md 0.4. Для работы нужен Node.js 24 и npm. Сборка не требует ключей внешних сервисов.

```sh
npm ci
npm test
npm run build
npm run dev
```

Открыть адрес, напечатанный сервером (по умолчанию `http://127.0.0.1:3000`). При запуске в удалённой среде loopback относится к серверу; используйте штатный проброс порта, а не этот адрес на другом компьютере.

`npm run dev` запускает HTTP API и Vite в одном процессе. `npm start` обслуживает готовый `dist/` и API. Production требует HTTPS через обратный прокси и корректный `APP_ORIGIN`, например `https://stand.example.ru`; cookie в этом режиме Secure. Публикация не выполнялась.

Переменные: `PORT` (3000), `HOST` (127.0.0.1), `DATABASE_PATH` (`data/a1.sqlite`), `APP_ORIGIN` (по умолчанию origin самого запроса). Доверие к proxy ограничено loopback. Не выставляйте стенд в интернет без проверки HTTPS, origin, резервирования и приёмки.

## Работа

1. Создать проект из контрольной карточки. Почта не требуется. Регион исходного примера — Башкортостан / Стерлитамак.
2. Редактировать размеры, поворот, положение, слои и проёмы в панели свойств. Золотые точки плана/3D изменяют габариты. Слои выбираются в дереве. Ошибочная команда не сохраняется.
3. Размеры участка и регион доступны в «Границы участка / новый вариант». Изменение создаёт независимый проект, сохраняя исходный; для этого не добавлена девятая команда геометрии.
4. Загруженный эскиз доступен для просмотра, выбора страницы PDF и подтверждения контрольной длины. Затем модель задаётся численно вручную. Автоматического распознавания нет.
5. Во вкладке сметы доступен фиксированный снимок и отрицательный пример отсутствующей третьей цены INS. XLSX выгружает точный сохранённый расчёт и сравнения.
6. TEST-ALT доступен во вкладке сравнения. Принятие меняет модель стенда; отмена/история возвращает исходный состав новой ревизией.
7. Экспорт JSON в панели участка и импорт в каталоге переносят геометрию в новый проект нового владельца. Вложения отдельно не переносятся JSON-экспортом.

Сессия живёт 30 дней. Закрытие браузера сохраняет cookie и проекты; очистка cookie/истечение сессии лишает доступа. CSRF восстанавливается GET /api/v1/session по cookie. Перенос проекта выполняется собственным JSON, не передачей cookie. Данные и вложения хранятся в SQLite вне публичной папки. Idempotency-Key, baseRevisionId и снимки обеспечивают повторы и конфликты. В незавершённом сетевом запросе браузер сохраняет ключ и повторяет тот же запрос.

## Резервирование и возврат

Простой согласованный для закрытого стенда способ: остановить процесс, скопировать всю `data/` в защищённое резервное хранилище, затем запустить. Для работающей БД используйте SQLite Online Backup API, не копируйте только основной `.sqlite` при открытом WAL. Сроки ежедневного резервирования/RPO/RTO — требования до выпуска, автоматическое внешнее резервирование здесь не настроено.

Восстановление: остановить процесс, сохранить текущую `data/` отдельно, вернуть проверенную копию, запустить и выполнить сценарий открытия/расчёта проекта. Совместимость схемы: user_version=1, неподдержанная старшая версия останавливает сервер. Точка возврата до реализации — e04c8fd; исходный утверждённый текст фиксируется вместе с кодом.

## Проверка

`npm test` запускает unit и реальные HTTP API проверки с временной SQLite; пользовательская БД не затрагивается. Искусственный сбой записи в тесте реализован SQLite-триггером, не открытым диагностическим API. `npm run build` проверяет TypeScript и собирает UI. Фактическое покрытие и непроверенные части — ACCEPTANCE.md.
